Golden Canopy Agritech – Turmeric Export Website

**Golden Canopy Agritech** is a professional agricultural export website designed to showcase and promote premium Indian turmeric products for the global market.

Key Features

* **Product Showcase** – Displays Turmeric Fingers, Turmeric Powder, and Organic Turmeric Powder with specifications and pricing.
* **Product Details** – Provides information about curcumin content, moisture, packaging, and quality standards.
* **Quality & Certifications** – Highlights certifications such as ISO 22000, USDA NPOP Organic, and GLOBALG.A.P.
* **Order & Inquiry System** – Allows customers to submit wholesale requirements and request customized quotations.
* **Company Information** – Provides details about the company, export operations, contact information, and business hours.
* **Responsive Design** – Provides a clean and professional interface for customers across devices.

 Technologies

* HTML
* CSS
* JavaScript


Objective

The goal of the project is to create a **professional digital platform for an agricultural export business**, allowing international buyers to explore products, view quality specifications, understand certifications, and submit wholesale inquiries.

Project Flow

**Explore Products → View Specifications → Check Certifications → Submit Inquiry → Receive Custom Quote**
